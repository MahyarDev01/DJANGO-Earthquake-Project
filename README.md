# 🌏 ساختار پروژه تحلیل داده‌های زلزله ژاپن

## معرفی پروژه

این پروژه با هدف جمع‌آوری، پاک‌سازی، ذخیره‌سازی، تحلیل داده‌های مربوط به زلزله‌های کشور ژاپن انجام می‌شود.

در این پروژه داده‌ها از چند منبع معتبر مانند:

- USGS API
- GEOFON
- EMSC
- Dataset 

جمع‌آوری شده و پس از پردازش و ذخیره‌سازی در پایگاه داده، تحلیل‌های آماری و نمودارهای مختلف روی آن‌ها انجام می‌شود.

---

## روند کلی اجرای پروژه

```
Data Collection
        ↓
Data Cleaning
        ↓
Database Storage
        ↓
SQL Analysis
        ↓
Data Visualization
        ↓

        ↓
Final Report
```
